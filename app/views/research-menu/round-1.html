What we're testing

ECMS replaces the legacy Document Repository Service (DRS) used in DWP to store and access documents. Although the new ECMS back-end is already released, we need to update user interface to make sure it’s accessible and easy to use.

This round of user research focuses on testing the search functionality for documents and the actions a user can perform with the returned search results.
